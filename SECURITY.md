# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

Cordis is an adversarial security and verification gate for CI/CD pipelines. If you discover a security vulnerability or an evasion technique that allows an untrusted/adversarial actor to bypass the Cordis prosecutorial gates (e.g. AST sandbox escape, mock spoofing, or CI token exfiltration), please report it responsibly.

Please do not open a public issue. Instead:
- Email **janmejai2002@gmail.com** with details of the vulnerability.
- Include a minimal reproduction script or diff that bypasses the gate.

We will acknowledge receipt within 48 hours and work with you on a patch and responsible disclosure timeline.
